# Nombres de la Biblia

Every person and place named in the Bible, laid out chapter by chapter in reading order. Each name links to the verses where it appears, opened in the Nueva Traducción Viviente (NTV) on BibleGateway.

Live site: https://jorsanchezch.github.io/nombres-biblia/

## Features

- Pick a range of books (opens on 1 Samuel – 2 Reyes).
- **Solo lista** view: every name listed in every chapter where it appears, in verse order. The lanes view gives each recurring name a vertical line from its first to its last appearance.
- Hold the pointer on a name for 1 second to highlight it and its family. Click it for details and all of its verses.
- ← / → jump between the books on screen.
- Hover over a verse link to read the verse.
